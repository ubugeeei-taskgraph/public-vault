# Migrate the past Vue Fes sites

## Outcome

Every past Vue Fes site is served from a maintained stack with working links and assets, without each edition keeping its own legacy build.

## Notes

Start by inventorying each past edition: where it is hosted, what stack it uses, and whether it still builds. Then decide per site whether to migrate it as-is or freeze it as static output. The Vue Fes 2019 tasks are the first concrete slice of this work.
