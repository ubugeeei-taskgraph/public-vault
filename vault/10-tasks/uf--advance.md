# Advance uf

## Outcome

Make uf the easiest way to build an app with Flow, from formatter and checker to dev server and UI kit.

## Notes

Created 2026-09-01 and immediately the busiest repo: about 760 PRs in September and uf@0.28.0 on 2026-10-04. Work so far covers parsing through Meta's Flow Rust port, a native Flow printer, TypeScript-to-Flow declaration translation, React Compiler lint rules, Relay, React Native targets, the UI registry, pm/env locking, and benchmarks. Most October work is fixes across check, ui, router, and vite.
